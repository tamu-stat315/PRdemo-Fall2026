# Contributing to PRdemo-Fall2026

Use this repository only for the STAT 315 pull request practice task.

## Acceptance criteria

Your pull request should:

- add exactly one new final line to `fav_animal.txt`;
- preserve every existing line;
- leave all other files unchanged;
- come from a branch named `dev` in your own fork; and
- explain the change and how you checked it.

## Workflow

1. Fork `tamu-stat315/PRdemo-Fall2026` on GitHub.
2. Clone your fork with the HTTPS URL from its **Code** menu.
3. Add `https://github.com/tamu-stat315/PRdemo-Fall2026.git` as the local remote named `upstream`.
4. Synchronize local `main` before beginning the change.
5. Create and switch to a branch named `dev`.
6. Append one animal, inspect the diff, stage the file, inspect the staged diff, and commit.
7. Push `dev` to your fork.
8. On GitHub, open a pull request from your fork's `dev` branch into this repository's `main` branch.
9. Read the review, revise the same branch if requested, and let the maintainer decide whether to merge.

## Keep the practice repository safe

Everything here is public. Do not include grades, graded work, passwords, access tokens, private datasets, or personal information.
